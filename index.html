Every automated step should leave a trail an auditor can follow

The test I apply to any AI or automation idea in Treasury: can each stage be explained, evidenced and reversed?

  1. CaptureBank and system data arrives from a known source.
  2. MatchRules or models pair items, with the logic recorded.
  3. FlagExceptions are logged, not silently cleared.
  4. ApproveA named person accepts each exception.
  5. PostEntries follow IFRS, with the trail kept.

Illustrative framework. It describes a control approach, not a specific system or result.
